# AWS Cloud Architecture & Infrastructure

## Overview
Expertise in designing and implementing cloud infrastructure on Amazon Web Services (AWS), including networking, compute, database, and managed services.

## Key Skills

### AWS Core Services
- **VPC (Virtual Private Cloud)**: Multi-AZ design, subnets, route tables, NAT Gateways, security groups
- **RDS (Relational Database Service)**: MySQL 8.0, Multi-AZ, parameter groups, backups, encryption
- **ECS (Elastic Container Service)**: Fargate, task definitions, services, auto-scaling
- **ALB (Application Load Balancer)**: HTTPS, target groups, health checks, routing
- **S3 & CloudFront**: Static hosting, CDN, caching, SSL/TLS certificates
- **ECR (Elastic Container Registry)**: Image storage, lifecycle policies, scanning
- **CloudWatch**: Logs, metrics, alarms, dashboards, insights
- **AWS Secrets Manager**: Secret storage and rotation

### CloudFormation & IaC
- Infrastructure as Code with YAML/JSON templates
- Stack management, nested stacks, parameters, outputs
- CloudFormation best practices and design patterns

### AWS Security
- IAM roles and policies with least privilege
- Security groups and network ACLs
- Encryption at-rest (KMS) and in-transit (TLS)
- VPC security architecture

### Auto-Scaling & Monitoring
- Target tracking policies
- Scaling cooldown and thresholds
- CloudWatch metrics and alarms
- Performance monitoring and optimization

- Implement 8 CloudFormation stacks
- Configure MySQL RDS with Multi-AZ and encryption
- Set up ECS Fargate auto-scaling (2-20 tasks)
